# Dragon — Machine Data

Drop all Dragon documentation here.

## What belongs here

| File | Description |
|------|-------------|
| `DRAGON-USER-MANUAL.pdf` | Official machine user manual |
| `dragon-wiring-diagram.pdf` | Full wiring schematic including CAN bus toolhead |
| `dragon-BOM.xlsx` | Bill of Materials |
| `printer.cfg` | Current production Klipper configuration |
| `macros.cfg` | Klipper macros (including ENCLOSURE_PREHEAT, BOWDEN_PURGE) |
| `dragon-build-photos/` | Sub-folder for build and maintenance photos |
