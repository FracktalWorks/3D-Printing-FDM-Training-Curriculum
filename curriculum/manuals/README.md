# Manuals & Reference Data

This folder holds official documentation, data sheets, and reference files for all machines and the factory slicer.

## Folder Structure

```
manuals/
├── snowflake/      ← Snowflake manual, wiring diagrams, BOM, CAD files
├── dragon/         ← Dragon manual, wiring diagrams, BOM, printer.cfg
├── twin-dragon/    ← Twin Dragon manual, IDEX config, wiring diagrams
└── fracktory/      ← Fracktory slicer guides, machine profiles, G-code templates
```

## What to Add in Each Folder

| Folder | Recommended Files |
|--------|-------------------|
| `snowflake/` | `Snowflake-User-Guide.pdf`, `snowflake-wiring.pdf`, `BOM.xlsx`, `printer.cfg` |
| `dragon/` | `Dragon-User-Guide.pdf`, `dragon-wiring.pdf`, `BOM.xlsx`, `printer.cfg` |
| `twin-dragon/` | `TwinDragon-User-Guide.pdf`, `idex-wiring.pdf`, `BOM.xlsx`, `printer.cfg` |
| `fracktory/` | `Fracktory-guide.pdf`, machine profile `.curaprofile` files, G-code templates |

## File Naming Convention

Use lowercase, hyphen-separated names. Include the machine name and version where applicable:

```
snowflake-user-guide-nov2025.pdf
dragon-user-guide-v5.pdf
fracktory-snowflake-profile-v1.curaprofile
```
