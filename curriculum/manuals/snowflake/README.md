# Snowflake — Machine Data

Drop all Snowflake documentation here.

## What belongs here

| File | Description |
|------|-------------|
| `SNOWFLAKE-USER-MANUAL.pdf` | Official machine user manual |
| `snowflake-wiring-diagram.pdf` | Full wiring schematic (PSU → board → motors → sensors) |
| `snowflake-BOM.xlsx` | Bill of Materials — all hardware, electronics, and consumables |
| `printer.cfg` | Current production Klipper configuration |
| `macros.cfg` | Klipper macros (START_PRINT, END_PRINT, CANCEL_PRINT) |
| `snowflake-build-photos/` | Sub-folder for build and maintenance photos |
