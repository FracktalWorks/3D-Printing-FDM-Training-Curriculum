## 🎯 Learning Objectives

- Slice a model using Fracktory and send it to a Fracktal printer
- Tune the critical slicer parameters (layer height, infill, supports, speed)
- Read and write basic G-code commands
- Understand the difference between Marlin and Klipper firmware
- Name the main 3D modeling tools and their use cases
