## 🎯 Learning Objectives

- Describe the FDM print process end-to-end
- Assemble and verify a printer before first use
- Perform manual and automatic bed leveling
- Calibrate E-steps, flow rate, and PID temperatures
- Send prints via Wi-Fi using Fracktory / OctoPrint
- Perform regular maintenance tasks
